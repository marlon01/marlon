# Film SELECTA : trois pistes

Film de lancement, 35 à 45 s, 16:9 en 1920×1080 à 30 i/s, version française puis anglaise (les
captures existent dans les deux langues : `docs/captures/selecta/fr` et `en`). Musique et bruitages
gratuits ; pas de voix off sauf demande, les titres et les écrans portent le texte.

Faits utilisés, tous tirés du code ou des captures : code d'accès personnel de 12 caractères,
valable une seule fois (60 bits d'entropie, jamais stocké en clair) ; contrôle d'identité par caméra,
visage comparé toutes les 8 secondes, analyse vidéo faite sur le poste ; une page validée ne se
rouvre pas ; résultat affiché dès la dernière page ; procès-verbal scellé par empreinte SHA-256 et
QR code, vérifiable par tous ; journal d'audit chaîné ; réponses conservées sur le poste si le
réseau coupe. Noms de candidats et de concours : fictifs, comme dans la base de démonstration.

Palette de la marque : encre `#14213D`, fond `#EEF1F7`, papier `#FBFCFE`, vert de validation
`#0E8A5F`.

---

## A. « Incontestable » — recommandée : la preuve finale est le moment que tout le monde comprend

**Procédé** : le résultat d'abord · **forme** : chaîne d'objet en objet.

Une main tend un téléphone vers un procès-verbal affiché sur un mur : le QR code est scanné,
« Document authentique » s'imprime en vert. La caméra remonte alors tout ce qui rend ce papier
inattaquable, objet par objet, jusqu'au code d'accès imprimé sur la convocation.

- **Deux premières secondes** : le viseur d'un téléphone verrouille le QR code du procès-verbal ; le
  sceau vert « Document authentique » tombe dessus.
- **Temps** : QR vérifié → l'empreinte SHA-256 se déroule et devient le journal d'audit chaîné → un
  maillon du journal s'ouvre sur l'épreuve chronométrée → le chronomètre recule jusqu'au contrôle
  caméra → le visage devient la convocation et son code à 12 caractères → retour au procès-verbal,
  titre « Des résultats que personne ne conteste » → carton final SELECTA.
- **Image** : papier officiel `#FBFCFE`, encre `#14213D`, le vert réservé au sceau ; uniquement les
  écrans réels, agrandis à 1,6–2×.
- **Son** : déclic de scan, coup de tampon, tic-tac discret du chronomètre ; une pulsation sobre qui
  s'ouvre au sceau final.

## B. « Le jour J »

**Procédé** : un moment dans la journée de quelqu'un · **forme** : un seul plan continu.

Un candidat, de dos, entre dans une salle d'examen. On le suit sans couper : il saisit son code, passe
le contrôle caméra, compose, valide sa dernière page et voit son résultat s'afficher, puis la caméra
s'élève au-dessus de la salle jusqu'à la console du jury qui voit tout en direct.

- **Deux premières secondes** : une convocation papier posée sur un clavier ; un doigt suit le code
  à 12 caractères.
- **Temps** : code saisi → contrôle caméra « Contrôle d'identité faciale validé » → épreuve et
  chronomètre → « Valider la page » → résultat et reçu → la caméra monte vers la surveillance en
  direct de la console → carton final.
- **Image** : la salle n'est jamais montrée en détail (silhouette, mains, clavier), les écrans
  réels portent tout ; lumière froide de salle d'examen.
- **Son** : pas, clavier, un seul souffle au moment du résultat.
- **Réalisme** : les plans de la personne demandent un tournage ou un générateur de vidéo payant
  (ManyMotions, avatar HeyGen) ; sinon mains et silhouette seulement.

## C. « Et si on trichait ? » — la plus audacieuse

**Procédé** : l'ancienne façon qui échoue, puis la nouvelle · **forme** : écran partagé qui se referme.

Le film essaie de tricher, et SELECTA l'en empêche à chaque fois. Chaque tentative est une phrase en
grand (« Je passe l'épreuve à sa place », « Je change la note », « Je regarde sur mon voisin ») ; à
droite, la vraie réponse du produit la bloque. À la fin, les deux moitiés se referment sur le
procès-verbal scellé.

- **Deux premières secondes** : « Je passe l'épreuve à sa place. » s'écrit en grand ; à droite, le
  contrôle d'identité affiche déjà « Visage non reconnu ».
- **Temps** : substitution → visage comparé toutes les 8 s → copier sur le voisin → ordre des
  questions mélangé pour chaque candidat → changer la note → journal d'audit immuable → l'écran se
  referme sur le sceau → carton final.
- **Image** : typographie géante encre sur papier côté triche, écrans réels côté produit ; rouge
  `#C2352B` pour chaque tentative barrée, vert pour la fin.
- **Son** : un buzzer sec à chaque blocage, rythme qui s'accélère, silence avant le sceau.
